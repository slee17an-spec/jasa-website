# 📦 MASTERS — TEMPLATE INTI (JANGAN DIEDIT LANGSUNG)

Folder **/masters** berisi **template utama (MASTER)** untuk semua jenis website.
File di folder ini **TIDAK BOLEH digunakan langsung untuk klien atau demo**.

## ⚠️ ATURAN UTAMA (WAJIB)
- ❌ Jangan edit file di `/masters`
- ❌ Jangan upload file master ke publik
- ✔ Selalu **COPY → RENAME → EDIT → DEPLOY**
- ✔ Edit **HANYA placeholder {{...}}**

---

## 🔁 ALUR KERJA RESMI (SOP RINGKAS)

1. Pilih master sesuai order
2. Copy file master
3. Rename sesuai kebutuhan
4. Edit **placeholder {{...}} saja** dengan cara Ctrl+H → Ganti placeholder → Deploy
5. Upload ke GitHub Pages
6. Cek link & tombol WhatsApp
7. Kirim ke klien

⏱️ Target produksi: **≤15 menit / website**
