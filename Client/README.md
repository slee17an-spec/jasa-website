# 👥 CLIENTS — WEBSITE KLIEN (PRODUKSI)

Folder **/clients** berisi **website klien nyata** yang sudah
dibuat berdasarkan master template.

⚠️ Folder ini **BERSIFAT PRODUKSI**.

---

## ATURAN UTAMA (WAJIB)
- ✔ Setiap file = 1 klien
- ✔ File di `/clients` BOLEH online (jika klien setuju)
- ❌ Jangan pakai data demo
- ❌ Jangan edit file di `/masters`

---

## 📂 STRUKTUR PENAMAAN (WAJIB KONSISTEN)

Format nama file:
jenis-usaha-nama.html


Contoh:
jasa-ac-jaya.html
bengkel-motor-makmur.html
toko-sembako-berkah.html


❌ Jangan pakai:
- spasi
- huruf besar
- simbol aneh

---

## 🔁 ALUR KERJA RESMI KLIEN

1. Copy file dari `/masters`
2. Paste ke `/clients`
3. Rename sesuai usaha klien
4. Edit **placeholder {{...}} saja**
5. Upload ke GitHub Pages
6. Tes website
7. Kirim link ke klien

⏱️ Target: **≤15 menit / klien**

---

## 🔒 DATA & PRIVASI
- Jangan simpan:
  - nomor pribadi selain WA publik klien
  - data sensitif
- Jika klien minta offline:
  - file tetap boleh disimpan di `/clients`
  - link tidak dibagikan publik
