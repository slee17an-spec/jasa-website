# 🎯 DEMO — CONTOH WEBSITE (PUBLIK)

Folder **/demo** berisi **contoh website (DEMO)** yang ditampilkan
di halaman utama `index.html` untuk meyakinkan calon klien.

## TUJUAN DEMO
- Memberi gambaran nyata ke calon klien
- Menunjukkan kualitas & gaya website
- Bukan website klien sebenarnya

---

## ⚠️ ATURAN WAJIB
- ✔ File di `/demo` BOLEH diakses publik
- ❌ Jangan taruh data klien asli
- ❌ Jangan pakai nama klien nyata (kecuali izin)
- ❌ Jangan hapus / rename tanpa update link di `index.html`

---

## 📂 STRUKTUR DEMO RESMI

/demo
├─ landing-jasa.html
├─ bio-link.html
├─ portfolio.html
├─ portal-konten.html (redirect ke Bisikan Sufi)
└─ README.md


### Penjelasan:
- `landing-jasa.html`  
  → Demo website jasa fokus WhatsApp

- `bio-link.html`  
  → Demo bio link usaha (alternatif Linktree)

- `portfolio.html`  
  → Demo portofolio (menampilkan semua demo)

- `portal-konten.html`  
  → **Redirect HTML** ke portal konten eksternal  
    (contoh: Bisikan Sufi)

---

## 🔁 ATURAN LINK INTERNAL (ANTI 404)
Karena semua file berada di folder yang sama:
- ✔ Gunakan link **relatif**
landing-jasa.html
bio-link.html
portfolio.html

- ❌ Jangan gunakan `/demo/` di dalam file demo

---

## 🔧 UPDATE DEMO
Jika demo diubah:
1. Update file di `/demo`
2. Cek ulang semua link demo
3. Tes via:
https://abdisyaif.com/demo/nama-file.html
